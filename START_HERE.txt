EDUCONNECT AI — KAISE CHALAYEIN (How to run)
=============================================

Ye folder me poora EduConnect AI project hai (Faculty-Student Academic Platform).

PEHLI BAAR CHALANE KE LIYE (First time setup):
----------------------------------------------
1. Is folder me Terminal / Command Prompt kholo:
   - File Explorer me is folder ko kholo
   - Address bar me "cmd" type karke Enter dabao

2. Ye commands ek-ek karke chalao:
       npm run setup
       npm run demo

3. Browser me kholo:  http://localhost:4000

AGLI BAAR CHALANE KE LIYE (Next time):
--------------------------------------
Sirf ek command:
    npm run demo

Database (demo data) pehli baar app chalne par apne aap ban jata hai.
Fresh demo data banane ke liye:
    npm run seed -- --reset   (ya: cd server aur phir: node seed.js --reset)
